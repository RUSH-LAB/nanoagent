## Findings
- [blocker] Citation Integrity: "DeepSeek-Prover-V1.5 combined MCTS with a process reward model that evaluates intermediate proof states, achieving near-state-of-the-art performance on formal mathematics benchmarks." -> This is factually wrong. DeepSeek-Prover-V1.5 (arXiv:2408.08152) does NOT use a learned process reward model. It uses RMaxTS, a Monte-Carlo tree search with intrinsic (reward-free) rewards to drive exploration, plus RLPAF reinforcement learning from a binary (0/1) proof-assistant outcome signal via GRPO. Rewrite to: V1.5 combines whole-proof generation with RMaxTS (an MCTS variant using intrinsic rewards) and RL from binary proof-assistant feedback. Remove the false PRM attribution. Also note it reached new SOTA on miniF2F (63.5%) and ProofNet (25.3%), not vaguely 'near-state-of-the-art'. RESOLVED.
- [blocker] Citation Integrity: "**DeepSeek-Prover** (Xin et al., 2024) [@xin2024deepseekprover] uses a large language model with Monte Carlo Tree Search to explore the proof space systematically." -> The citekey @xin2024deepseekprover resolves to DeepSeek-Prover (V1), 'Advancing Theorem Proving in LLMs through Large-Scale Synthetic Data' (arXiv:2405.14333). But the surrounding text describes V1.5-specific results (MCTS/tree search, intermediate-state evaluation, near-SOTA). V1 is a large-scale synthetic-data SFT prover and does NOT use MCTS. Either add a separate references.yaml entry for DeepSeek-Prover-V1.5 (arXiv:2408.08152) and cite it for the V1.5 claims, or rewrite the paragraph to correctly attribute the search method to V1.5 with the right citation. As written the MCTS claim is credited to the wrong paper. RESOLVED.
- [major] Problem Formulation & Eval Rigor: "substantially improving accuracy on competition math benchmarks (MATH dataset accuracy improved from 50% to 78% with PRM-guided search)." -> The 78% endpoint is correct (the paper reports 78.2% solved on a representative MATH subset via best-of-1860 PRM reranking). But the '50%' starting point is unsourced and not the paper's reported baseline: the comparable best-of-1860 numbers are ORM 72.4% and majority voting 69.6%. The '50% to 78%' framing overstates the PRM gain. Replace with the paper's actual comparison: PRM 78.2% vs ORM 72.4% vs majority-vote 69.6% (best-of-1860), and drop the unsupported 50% figure. RESOLVED.

# Mochi Lab

A research and knowledge-sharing site built with [Docusaurus](https://docusaurus.io/), deployed on [Vercel](https://vercel.com/), with [Clerk](https://clerk.com/) authentication.

## Prerequisites

- [Node.js](https://nodejs.org/) (v20+)

## Getting Started

```bash
cd mochi-lab
npm install
npm start
```

Opens a local dev server at `http://localhost:3000`.

## Deployment

Deployed automatically via Vercel on push.

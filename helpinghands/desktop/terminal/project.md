# This folder is the plugin {{id}}

RUSH Lab made this folder with `nanoagent plugin new`, so it is already the plugin `{{id}}`,
started from the template, with its id, name, project name and LICENSE filled in: skip the
clone in step 2 of the skill below, and keep this folder.

- `nanoagent plugin inspect .` checks it against every plugin rule.
- `rushlab preview .` shows it in RUSH Lab, under Plugins → Drafts, before it is published.

`AGENTS.md`, `CLAUDE.md` and `GEMINI.md` hold this same text, one for each coding agent. They
are never packed into the plugin.

\section{Publishing on RUSH Lab}

\begin{enumerate}
  \item Push the complete, tested plugin to a public GitHub repository.
  \item Sign in at \url{https://rush-lab.org} and open the course workspace,
    \url{https://rush-lab.org/w/comp-480-580}. Add an OpenRouter API key and
    choose the model under \textbf{Settings $\rightarrow$ AI}.
  \item In the workspace's \textbf{Marketplace}, select \textbf{+ Publish a plugin}, paste
    the repository URL (for a subfolder,
    \nolinkurl{https://github.com/<owner>/<repo>/tree/<branch>/<folder>}),
    and select \textbf{Publish}. Fix any reported errors and publish again.
  \item Once a course workspace owner adds it, open the plugin, ask the chat for the
    task, and check the verdict on its result card. \textbf{Passing the
    publication checks shows the format, not that the task or verifier is
    correct}: the verifier's tests and the runs' verdicts show that.
\end{enumerate}

\section{Publishing on Mochi Lab}

\begin{enumerate}
  \item Push the complete, tested plugin to a public GitHub repository.
  \item Sign in at \url{https://rush-lab.org}, and add an OpenRouter API key
    and choose the model under \textbf{Settings $\rightarrow$ AI}.
  \item In \textbf{Marketplace}, select \textbf{+ Publish a plugin}, paste
    the repository URL (for a subfolder,
    \nolinkurl{https://github.com/<owner>/<repo>/tree/<branch>/<folder>}),
    and select \textbf{Publish}. Fix any reported errors and publish again.
  \item Once a workspace owner adds it, open the plugin, ask the chat for the
    task, and check the verdict on its result card.
\end{enumerate}

\textbf{Passing the publication checks shows the plugin follows the format,
not that its task or verifier is correct.} The verifier's tests and the
runs' verdicts show that.

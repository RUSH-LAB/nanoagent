\section{What a plugin is}

An agent saying it has finished a task does not show that its result is
right. Judging an agent takes a precise task, an environment anyone can
reproduce, and a verifier that checks the actual result. A NanoAgent plugin
packages all three: typed tools served over MCP, tasks built from them, a
deterministic verifier, and a front end, NanoAgent's chat, which runs the
tasks and shows each result with its verdict. NanoAgent loads a plugin only
when every \texttt{nanoagent.plugin/v1} rule below holds, rechecks them on
every tool call, and lists every broken rule at once.

# Linear Algebra

- **[Eigendecomposition](./3-eigendecomposition.md)** -- Eigenvalues, eigenvectors, spectral theorem, and positive definiteness
- **[SVD and PCA](./4-svd-and-pca.md)** -- Singular value decomposition, low-rank approximation, and principal component analysis
- **[Matrix Calculus](./5-matrix-calculus.md)** -- Gradients of scalar, vector, and matrix functions, Jacobians, and Hessians

This chapter documents the building blocks for writing textbook-style content. Each section covers a specific component type with usage examples.

- <PageRef path="./figure-and-table" />: auto-numbered, captioned figures and tables
- <PageRef path="./math" />: theorem-like environments, proofs, and equations
- <PageRef path="./code" />: code listings and algorithm pseudocode
- <PageRef path="./paper-citation" />: cite papers with `[@key]` syntax
- <PageRef path="./cross-reference" />: link to any numbered element with `<Ref>`

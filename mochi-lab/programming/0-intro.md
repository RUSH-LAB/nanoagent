# Welcome

Welcome to the programming journey! This textbook covers everything an ML engineer needs to build and ship models, from computing fundamentals to distributed training systems.

## Chapters

- **[Introduction to Computing](intro-to-comp)** -- How programs execute: CPU/GPU architecture, memory hierarchy, the abstraction stack, and high-performance computing
- **[Deep Learning with PyTorch](torch)** -- Tensors, autograd, nn.Module, data loading, training loops, and debugging
- **[CUDA and GPU Programming](cuda-and-gpu)** -- Writing GPU kernels: CUDA, memory model, optimization, Triton, and custom ops
- **[Assembly and Low-Level Programming](assembly)** -- x86 basics, memory and stack, SIMD instructions
- **[ML Systems](ml-systems)** -- Distributed training, mixed precision, inference optimization, and profiling
- **[Supplementary Materials](supplement)** -- Python tips, Linux/shell, and Git for ML

## Getting Started

Start with [Introduction to Computing](intro-to-comp) to build your foundation, then work through PyTorch and CUDA before tackling ML systems.

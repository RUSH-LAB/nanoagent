# Welcome

Welcome to the programming journey! This textbook covers everything an ML engineer needs to build and ship models, from computing fundamentals to distributed training systems.

## Chapters

- **[Introduction to Computing](./1-intro-to-comp/)** -- How programs execute: CPU/GPU architecture, memory hierarchy, the abstraction stack, and high-performance computing
- **[Deep Learning with PyTorch](./2-torch/)** -- Tensors, autograd, nn.Module, data loading, training loops, and debugging
- **[CUDA and GPU Programming](./3-cuda-and-gpu/)** -- Writing GPU kernels: CUDA, memory model, optimization, Triton, and custom ops
- **[Assembly and Low-Level Programming](./4-assembly/)** -- x86 basics, memory and stack, SIMD instructions
- **[ML Systems](./5-ml-systems/)** -- Distributed training, mixed precision, inference optimization, and profiling
- **[Supplementary Materials](./99-supplement/)** -- Python tips, Linux/shell, and Git for ML

## Getting Started

Start with [Introduction to Computing](./1-intro-to-comp/) to build your foundation, then work through PyTorch and CUDA before tackling ML systems.

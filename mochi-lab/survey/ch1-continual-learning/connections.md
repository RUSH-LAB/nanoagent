# Connections to Other Chapters

**Efficient Architecture Design (Chapter 3):** Architecture-based continual learning methods are closely related to efficient architecture design. Mixture-of-Experts models naturally support continual learning by routing new tasks to new experts while freezing old ones, providing both computational efficiency and forgetting prevention. Parameter-efficient fine-tuning methods (LoRA, adapters) from Chapter 3 serve dual purposes: enabling efficient inference and facilitating continual learning by limiting the number of parameters modified per task. The sparse activation patterns in MoE models reduce interference between tasks, and the dynamic expert addition mechanism mirrors the expansion strategies in continual learning. State space models (Mamba) with their recurrent structure may offer advantages for online continual learning settings where data arrives sequentially.

**World Models (Chapter 2):** Continual learning is essential for world models that must adapt to changing environments. A robot's world model must update as it encounters new objects, environments, or physical interactions, making catastrophic forgetting a practical concern for model-based reinforcement learning. Dreamer-style agents deployed in non-stationary environments face the classic stability-plasticity dilemma: the dynamics model must adapt to new environments while retaining knowledge of previously learned physics. The complementary learning systems framework that inspires replay-based continual learning also provides a blueprint for how world models might consolidate environmental knowledge.

**Agentic Search (Chapter 4):** Agents that interact with evolving knowledge bases must continually update their retrieval and reasoning capabilities. Continual learning of retrieval models is necessary as document collections grow and change -- the retriever must index new documents without degrading retrieval quality for existing queries. Knowledge editing in LLMs (Section 1.8) connects to RAG systems where the model's parametric knowledge must be kept consistent with the retrieved evidence. Self-improving search agents that learn from their search experiences over time face a continual learning challenge: how to accumulate search strategies without forgetting effective approaches.

**Randomized Algorithms (Chapter 5):** Sketching and hashing techniques from Chapter 5 can be applied to continual learning in several ways: compressed replay buffers using sketching reduce the memory cost of exemplar storage; random projections enable efficient computation of parameter importance (for EWC-style methods) without materializing the full Fisher matrix; streaming PCA algorithms can track the evolving representation subspace for methods like GPM; and reservoir sampling provides the theoretical foundation for replay buffer management. The streaming algorithms perspective -- processing data in a single pass with bounded memory -- provides a natural formal framework for online continual learning.

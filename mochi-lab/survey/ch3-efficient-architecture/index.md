# Efficient Architecture Design of AI

This chapter surveys the landscape of efficient architecture design for AI systems. As scaling frontiers push model sizes and compute budgets to unprecedented levels, efficiency has become a first-class design objective. We cover efficient attention mechanisms, Mixture-of-Experts, neural architecture search, model compression, training and inference optimization, state space models, and sub-quadratic architectures.

## Connections to Other Chapters

**World Models (Chapter 2):** World models and agentic search share the fundamental principle of model-based planning -- using an internal model to simulate outcomes before committing to actions. MuZero-style planning with learned world models is structurally identical to tree search in agentic reasoning: both explore a tree of possibilities, evaluate states, and select the most promising path. Agentic search can also be viewed as building a **world model of the information landscape** -- understanding what information exists, where it is located, how it is structured, and how to access it efficiently. The dynamics model in world model RL (predicting the next state given an action) is analogous to the retrieval model in agentic search (predicting what information will be returned given a query). Video world models that predict visual futures are analogous to search agents that predict what evidence will be found.

**Efficient Architectures (Chapter 3):** The computational cost of agentic search is dominated by LLM inference calls -- an agent that issues 100 queries to an LLM during a single research task amplifies the cost of each query by the fan-out factor. Efficient inference techniques (speculative decoding, KV-cache optimization, quantization from Chapter 3) directly impact the economic viability of agentic search. Multi-turn agentic conversations can reuse KV-cache across turns (RadixAttention in SGLang), connecting serving system design to agentic workflow efficiency. Efficient embedding models are critical for the retrieval component of RAG systems -- the tradeoff between bi-encoder speed and cross-encoder quality (ColBERT's late interaction is a middle ground) directly affects search latency. MoE models are particularly relevant for agentic systems that must switch between different modes (retrieval, reasoning, generation, tool use), as different experts can specialize in different modes.

**Continual Learning (Chapter 1):** Search agents that operate over extended periods must continually update their knowledge of available information sources, search strategies, and domain expertise. Retrieval indices must be updated as new documents are added or existing ones change, creating a **continual learning challenge for the retrieval component** -- the retriever must incorporate new documents without degrading retrieval quality for existing queries. Knowledge editing in LLMs (Chapter 1) connects to RAG systems where the model's parametric knowledge must be kept consistent with retrieved evidence -- when the parametric and retrieved knowledge conflict, the system must decide which to trust. Self-improving search agents that learn from their search experiences face the classic stability-plasticity tradeoff: how to accumulate effective search strategies without forgetting strategies that worked for previous types of questions.

**Randomized Algorithms (Chapter 5):** Approximate nearest neighbor search -- the computational backbone of dense retrieval in RAG systems -- relies fundamentally on randomized data structures from Chapter 5. Locality-sensitive hashing enables sub-linear retrieval from billion-scale document collections. Random projections reduce the dimensionality of embedding spaces for efficient indexing. HNSW (Hierarchical Navigable Small World) graphs use randomized graph construction for efficient approximate nearest neighbor search. The efficiency of vector search (measured in queries per second at a given recall level) directly impacts the viability of retrieval-heavy agentic systems. Bloom filters enable efficient membership testing for deduplication of retrieved documents. Count-Min sketches can track query frequency distributions for cache optimization in retrieval systems. The streaming algorithms perspective from Chapter 5 provides the theoretical framework for processing retrieval results in a single pass with bounded memory.

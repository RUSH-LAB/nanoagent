## Benchmarks & Evaluation

### Retrieval Benchmarks

- **KILT** (Petroni et al., 2021) [@petroni2021kilt]: Knowledge Intensive Language Tasks, a unified benchmark covering fact-checking, question answering, slot filling, entity linking, and dialogue, all requiring retrieval from Wikipedia.
- **BEIR** (Thakur et al., 2021) [@thakur2021beir]: Benchmarking IR, a heterogeneous benchmark of 18 retrieval datasets spanning diverse domains and task types, evaluating zero-shot retrieval performance.

### Question Answering Benchmarks

- **HotpotQA** (Yang et al., 2018) [@yang2018hotpotqa]: Multi-hop question answering requiring reasoning over two or more Wikipedia paragraphs.
- **FEVER** (Thorne et al., 2018) [@thorne2018fever]: Fact Extraction and VERification, requiring systems to verify claims against Wikipedia evidence.
- **Natural Questions** (Kwiatkowski et al., 2019) [@kwiatkowski2019natural]: Real Google search queries with answers from Wikipedia.

### Agent Benchmarks

- **WebArena** [@zhou2024webarena]: Realistic web interaction tasks on self-hosted websites.
- **Mind2Web** [@deng2024mind2web]: Real-world web task completion across 137 websites.
- **GAIA** (Mialon et al., 2024) [@mialon2024gaia]: General AI Assistants benchmark requiring multi-step tool use and reasoning.
- **SWE-bench** (Jimenez et al., 2024) [@jimenez2024swebench]: Software engineering tasks requiring agents to find and fix real GitHub issues.

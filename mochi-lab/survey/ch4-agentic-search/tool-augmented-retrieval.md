## Tool-Augmented Retrieval

### WebGPT

Nakano et al. (2022) [@nakano2021webgpt] developed WebGPT, one of the first systems to train an LLM to use a web search engine as a tool. WebGPT was fine-tuned via human feedback to issue search queries, click on results, quote passages, and compose answers with citations. Trained with both behavior cloning and reinforcement learning from human feedback, WebGPT demonstrated that LLMs could learn effective search strategies, often outperforming humans on the ELI5 long-form question-answering benchmark.

### Toolformer

Schick et al. (2023) [@schick2023toolformer] introduced Toolformer, which teaches LLMs to use external tools (including search engines, calculators, and translation APIs) in a self-supervised manner. Rather than requiring human demonstrations, Toolformer uses the LLM itself to generate and filter tool-use annotations, then fine-tunes on the successful ones. This bootstrapping approach scales more easily than human-supervised methods.

### ReAct

Yao et al. (2023) [@yao2023react] proposed ReAct (Reasoning + Acting), a prompting framework where the LLM alternates between reasoning traces (thinking about what to do) and actions (search queries, lookups). By interleaving reasoning with action, ReAct enables more systematic and interpretable search strategies than pure action-based approaches. ReAct has become a foundational pattern for LLM-based agents.

### TALM

Parisi et al. (2022) [@parisi2022talm] proposed TALM (Tool Augmented Language Models), which iteratively fine-tunes language models on tool-use examples generated by the model itself. TALM demonstrated that tool-use capability improves with scale and that self-generated training data can bootstrap effective tool-use learning.
